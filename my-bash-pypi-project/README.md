# FOSSDEV: Монорепозиторий учебных проектов

Этот репозиторий содержит инструменты для автоматизации сборки и публикации Python-пакетов.

## Проекты
1. **simple-math-flow**: Библиотека для выполнения арифметических операций в "поточном" стиле.

## Быстрый старт (Автоматизация)
Все ключевые действия выполняются через `Makefile` из корня:
* `make venv` — создание окружения и установка инструментов.
* `make install` — установка библиотеки в режиме разработки.
* `make test` — запуск unit-тестов.
* `make lint` — проверка качества кода и типов.
* `make build` — сборка дистрибутивов (.whl и .tar.gz).
