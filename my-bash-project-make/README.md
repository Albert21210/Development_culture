# Автоматизация Python-проекта: GNU Make и Stateless-окружение

## Логика решения
Проект построен на принципе **воспроизводимости**. Вместо ручной настройки окружения используется `Makefile`, который выступает диспетчером всех процессов.

### Ключевые особенности:
1. **Явные пути:** Мы не используем `source activate`. Все вызовы идут напрямую через `.venv/bin/python`.
2. **Контроль качества:**
   - `make typecheck` — ловит ошибки типов (mypy).
   - `make lint` — проверяет соответствие PEP8.
   - `make check-requirements` — анализирует, не забыли ли мы пакет в конфиге.
3. **Цепочки:** Команда `make check` запускает полный цикл проверок.

## Как запустить
1. Склонируйте репозиторий.
2. Выполните `make install` для сборки окружения.
3. Выполните `make check` для верификации кода.
4. Выполните `make run` для запуска приложения.
