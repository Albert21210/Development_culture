Аналитика качества программного обеспечения
Концепция

В больших проектах количество тестов исчисляется тысячами. Простого статуса "Passed/Failed" недостаточно для оценки динамики разработки. qa-metrics-toolkit — это библиотека, которая превращает сырые отчеты тестирования в понятные метрики качества (Quality Gates).
Реализация и логика

Библиотека реализует парсинг артефактов тестирования в формате JUnit XML.

    Анализ стабильности: Вычисление коэффициента успешности по формуле S=Ttotal​Tpass​​×100%.

    Временной профиль: Определение самых "тяжелых" тестов, замедляющих пайплайн разработки.

Автоматизация (Makefile)

Проект следует строгим правилам автоматизации:

    Линтинг: Использование ruff для проверки стиля.

    Типизация: Проверка через mypy.

    Сборка: Использование модуля build для создания .whl архивов.
